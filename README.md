# TypeScript Assignment 1

## Overview

This repository contains my TypeScript assignment, focusing on fundamental and advanced TypeScript concepts, including functions, generics, interfaces, OOP, and asynchronous programming.

### Topics Covered

- **Functions:** Default parameters, return types, and basic calculations.
- **Type Handling:** Generic functions and type checking using `typeof`.
- **Tuples:** Working with readonly tuples and destructuring.
- **Generics:** Combining arrays and creating reusable functions.
- **Interfaces:** Defining object structures and filtering data.
- **Keyof Constraint:** Extracting specific property values from objects using generics.
- **OOP:** Implementing classes, inheritance, and access modifiers (`protected` and `private`).
- **Async Programming:** Handling asynchronous operations using Promises and `async/await`.
